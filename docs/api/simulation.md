# Simulation (`crimsons.simulation`)

The top-level entry point: ties an IMF, a lifetime function, and a set of
channels together into an ensemble of Monte Carlo realizations. See
[Quickstart](../getting-started/quickstart.md) for a walkthrough and
[Physics Overview](../physics/index.md) for what happens inside `run()`.
