# Contributing

All efforts to improve CRIMSONS are wellcomed. We ask any contributor to follow the simple four steps below:

1. Fork and branch from `main`.
2. Keep changes focused; add/update tests and docs alongside code changes.
3. Make sure `pytest` and `mkdocs build --strict` both pass locally.
4. Open a PR describing what changed and why.

For any questions, bugs or issue, please contact: lapo.querci1@unifi.it
